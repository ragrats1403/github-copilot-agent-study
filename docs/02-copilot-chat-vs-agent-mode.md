# 02 - Copilot Chat vs Agent Mode

## Purpose

This document explains the difference between GitHub Copilot Chat and Agent Mode as part of OD-001: GitHub Copilot Study.

The goal is to understand when to use normal chat and when to use agent-based workflows.

---

## Simple Difference

Copilot Chat is best for asking questions, getting explanations, and receiving focused suggestions.

Agent Mode is best for multi-step work where Copilot needs to inspect files, make changes, run commands, and validate results.

Simple comparison:

```text
Copilot Chat = conversation and assistance
Agent Mode   = task execution with tools
