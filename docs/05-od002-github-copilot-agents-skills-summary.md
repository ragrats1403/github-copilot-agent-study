# OD-002 - GitHub Copilot Agents and Skills Summary

## Objective

Create and validate generic GitHub Copilot prompts, skills, and agents for common software development workflows.

The workflows covered are:

1. Coding / Feature Creation
2. Automated Testing
3. Development Estimation
4. Code Review

## Scope

This work focused on creating reusable and generic Copilot assets that can adapt to different repositories and technology stacks by inspecting repository context before producing plans, estimates, tests, or reviews.

The proof of concept used an Angular Employee Management sample application.
