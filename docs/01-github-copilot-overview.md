# 01 - GitHub Copilot Overview

## Purpose

This document summarizes the basic concepts of GitHub Copilot as part of OD-001: GitHub Copilot Study.

The goal is to understand what GitHub Copilot is, what it can do, and how it supports software development workflows.

---

## What is GitHub Copilot?

GitHub Copilot is an AI-assisted software development tool integrated with GitHub and supported development environments such as Visual Studio Code.

It helps developers with tasks such as:

- Code suggestions
- Code explanation
- Debugging assistance
- Refactoring
- Test generation
- Code review
- Documentation
- Repository analysis
- Agent-based workflows

GitHub Copilot should be treated as a developer assistant, not a replacement for the developer.

---

## Why is it called Copilot?

A copilot assists the main pilot.

In software development, the developer remains responsible for understanding requirements, reviewing code, validating behavior, and ensuring quality.

Copilot can suggest and automate parts of the work, but the developer must still make the final decision.

Copilot is not autopilot.
